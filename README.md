# Quick-Dukaan
A full-stack e-commerce app for kirana stores.

## Run locally
1. Install dependencies: npm install
2. Create a .env file based on .env.example
3. Start the server: npm start
4. Open http://localhost:3000

## Deploy
- Use a Node.js hosting platform such as Render, Railway, or Fly.io
- Set the environment variable MONGODB_URI to your MongoDB Atlas connection string
- Set PORT to 3000 or let the platform assign one automatically
